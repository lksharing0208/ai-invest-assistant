# 金融数据源接入规范

## 1. 数据源注册

每个真实数据源在部署配置中登记：
- provider_id、供应商名称和环境；
- 覆盖市场、证券类型和字段；
- 实时/延迟/历史能力及延迟说明；
- API/MCP 传输方式和认证方案；
- 数据许可范围和再分发限制；
- 限流、配额、超时、可用性和故障策略；
- 数据更新时间、修订和历史回补行为。

不得在本仓库提交真实 Token、密钥或个人账户凭证。

## 2. 适配层

供应商差异在 Data Adapter/MCP 层处理，输出统一的证券标识、时间、单位、币种、数据状态、来源和质量标记。Skills 不绑定供应商私有字段。

## 3. 数据核验

- 对照供应商文档确认字段含义和单位；
- 确认时间戳代表撮合时间、收盘时间还是入库时间；
- 财务数据区分报告期和公开披露日；
- 核实复权、分红、拆股、退市和成分调整；
- 对冲突源保留差异和选用理由；
- 数据供应商故障时不得静默切换到口径不同的数据源。

## 4. 上线验收

需覆盖字段映射、市场覆盖、时间边界、节假日、异常值、延迟标记、重试、配额、权限和审计。正式启用前需经过数据质量验收。
