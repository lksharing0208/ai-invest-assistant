# 金融数据标准

## 统一原则

任何进入分析链路的数据都应可识别来源、时间、市场、证券标识、单位、币种和统计口径。

## 市场数据

价格序列保留交易所时区和复权方式；成交金额、数量、价格单位需明确；交易日由真实市场日历确定。

## 财务数据

保留报告期、披露日期、币种、合并/母公司口径、会计准则、单位和修订状态。历史分析应使用当时已披露的数据，避免财报前视。

## 新闻与公告

保留发布主体、发布时间、事件发生时间（如不同）、原文来源和适用公司/市场。模型摘要不能替代原始来源。

## 质量状态

建议统一为 valid、delayed、historical、estimated、missing、conflict、stale、invalid 等状态。状态枚举需由具体数据适配器落实，不得仅靠文本推断实时性。

## 缺失和冲突

未知数据保留为缺失；不自动用零填充。冲突数据同时保留来源和差异，说明后续处理方式。
