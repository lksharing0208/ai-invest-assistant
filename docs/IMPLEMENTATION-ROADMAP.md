# AI 金融助手实施路线图

## 阶段 A：Agent 与基础数据规范

- 统一 Agent 源配置和主控 Skill；
- 意图路由、S0-S3 分级和低 Token 策略；
- 数据质量规范和数据源注册模板；
- 基础安全策略和 Skills 校验。

**退出条件：** 路由样例可评估；数据源注册、数据时间、市场和证券标识规范确定。

## 阶段 B：研究能力

- 宏观、市场、行业和个股研究；
- 基金 ETF 研究；
- 投资报告模板和证据引用规范。

**退出条件：** 能基于真实接入数据生成带来源和时间的研究结果，并覆盖数据缺失与冲突场景。

## 阶段 C：指标选股和策略

- 指标目录、股票池和过滤配置；
- 评分、分级、排序和淘汰原因；
- 突破—回踩—启动状态机；
- 回测、样本外验证和参数敏感性分析。

**退出条件：** 规则版本化、无未来函数、交易成本和滑点建模，策略经过独立评审。策略默认禁用，未经验证不进入实盘。

## 阶段 D：组合和风险

- 账户与持仓接入；
- 组合资产、行业和币种暴露；
- 风险限额、压力情景和交易计划；
- 用户级数据隔离和敏感访问审计。

**退出条件：** 身份与账户授权闭环完成，读写隔离测试通过，风险配置经过用户/策略审批。

## 阶段 E：交易记录和绩效

- 交易计划、委托、成交和持仓批次的状态区分；
- 每日操作记录和复盘；
- 收益、回撤、胜率、盈亏比和策略绩效；
- 费用、现金流、分红和汇率统一口径。

**退出条件：** 交易记录幂等和审计完整，绩效指标口径经过测试，样本不足能正确提示。

## 阶段 F：平台适配和插件交付

- ChatGPT Plugin Adapter；
- Claude / OpenAI Runtime Adapter；
- ZIP 构建、静态校验和路由验收；
- 平台导入后的 Skills 发现及行为测试。

**退出条件：** 插件根清单、主控 Agent、16 个 Skills 和必要参考文件均可识别；实际平台行为完成验证。

## 当前状态

当前仓库提供规范、Skills、配置模板、适配源文件和本地校验/打包脚本。真实行情服务、身份账户、个人持仓数据库、回测引擎与交易执行服务仍属于后续实施范围。
