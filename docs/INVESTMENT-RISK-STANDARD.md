# 投资风险标准

## 风险覆盖

市场、个体、行业集中度、流动性、杠杆、策略、操作、汇率及跨境风险。

## 分析流程

识别风险对象 → 校验数据 → 读取已批准限额 → 量化与压力测试 → 评价触发状态 → 给出缓释选项 → 说明剩余风险。

## 配置原则

risk-config 中 null 表示未配置，不等同于无限额或零风险。没有有效的用户/策略限额时，不得输出“已满足风险要求”。

## 交易计划

止损不保证成交；跳空、停牌、流动性不足和交易限制可能导致损失超过计划值。仓位计算必须纳入合约乘数、最小交易单位、费用、滑点和汇率。

## 权限

分析、模拟和真实交易执行分离。真实交易需独立的已授权交易工具、用户确认、账户权限校验和执行回执。
