# 指标选股与股票筛选

## 1. 职责

把用户明确的选股条件转为可执行、可追溯的筛选流程。指标定义、周期、阈值、权重和股票池必须从项目配置或用户输入读取，不能在 Skill 中擅自固化为投资建议。

## 2. 流程

1. 明确市场、股票池、证券类型、观察日期和流动性边界。
2. 读取 screening-config、指标口径和数据质量策略。
3. 通过 market-data 获取必要价格、成交、财务、行业和公司行为数据。
4. 执行基础预过滤：证券状态、上市时间、停牌、流动性、风险排除规则（按配置）。
5. 计算配置启用的指标，逐项检查所需样本长度、复权口径和缺失值。
6. 按配置执行趋势、动量、波动、量价、基本面和行业过滤。
7. 对符合条件的候选按配置评分、分级和排序。
8. 输出过滤漏斗、入选依据、未通过原因、数据质量标记和候选清单。
9. 如策略规则涉及突破/回踩/再启动，转交 strategy-analysis 评估状态和触发条件。

## 3. 指标与评分要求

每个指标配置需要定义：
- 唯一标识和业务说明；
- 输入字段、单位和计算公式；
- 时间周期、采样频率和复权口径；
- 方向（越高越好、越低越好、区间适中或布尔条件）；
- 阈值、权重、缺失处理和适用市场；
- 配置版本、生效时间和变更记录。

评分需说明归一化方法、权重、分级边界和并列排序策略。不得将不同量纲的原始指标直接相加；缺失指标不得默认为零分，除非策略明确声明此规则并说明影响。

## 4. 防偏差

- 只使用观察时点已经可获得的数据，财报按披露日而非报告期结束日进入历史筛选。
- 回测股票池须考虑退市和历史成分变化，避免幸存者偏差。
- 防止未来函数、复权因子前视和数据泄漏。
- 明确停牌、涨跌停、交易成本、滑点和不可成交情况。
- 样本不足或数据质量不合格时拒绝给出伪精确排名。

## 5. 输出

股票池规模、各阶段过滤数量、候选列表、指标计算明细、综合得分/等级、每只股票的入选和淘汰原因、数据时点、配置版本、风险提示及待补数据。
