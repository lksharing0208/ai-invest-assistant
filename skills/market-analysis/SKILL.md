# 市场与大盘分析

## 1. 任务边界

分析市场整体状态，不替代个股基本面研究。先确认市场、指数、交易日和分析时间，避免跨市场时间错配。

## 2. 分析维度

- 主要指数：价格变化、趋势、波动和相对表现；
- 成交：成交金额/量、相对历史水平及量价关系；
- 市场广度：上涨/下跌/平盘家数、创新高低数量（数据可得时）；
- 结构：行业、风格、大小盘和主题表现；
- 波动与风险：波动率、跳空、流动性和市场集中度；
- 情绪：涨跌停、成交集中、风险偏好代理指标（适用市场）；
- 事件：重要经济数据、政策、公司事件及全球市场联动。

## 3. 执行步骤

1. 通过 market-data 获取选定指数和市场广度数据。
2. 校验市场交易时段、数据时点、成分股口径和缺失情况。
3. 分析趋势、量价、广度和行业结构是否相互印证。
4. 识别市场环境：趋势、震荡、波动放大或流动性压力等描述性状态。
5. 评估宏观及事件风险；仅在确有必要时调用 macro-analysis。
6. 输出事实、判断、证据和判断失效条件。

## 4. 规则

- 不把指数上涨直接等同于市场整体强势。
- 不用单一交易日推断长期趋势。
- 市场宽度数据必须说明样本范围与统计口径。
- 盘前分析须区分上一交易日收盘事实、盘前数据和尚未开盘的预期。
- 不同市场不共用未经验证的涨跌停、交易时段或情绪指标定义。

## 5. 输出

市场与时间、指数表现、成交和广度、行业结构、波动/情绪、事件影响、市场状态判断、风险及盘中观察条件。
