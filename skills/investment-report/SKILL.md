# 投资研究报告

## 1. 职责

组织研究结果和证据，形成结构清楚、可复核的投资报告。该 Skill 不替代专业数据获取、个股研究或风险分析；复杂内容应调用对应 Skills。

## 2. 报告类型

- 盘前市场解读；
- 每日/每周市场复盘；
- 宏观与行业研究；
- 个股研究报告；
- ETF 比较报告；
- 策略筛选和回测报告；
- 个人投资组合报告；
- 交易计划与复盘报告。

## 3. 执行流程

1. 明确报告目的、读者、市场、对象、时间范围和输出格式。
2. 按需选择主研究 Skill；综合报告只加载确实需要的辅助 Skills。
3. 汇总真实数据源、数据时间、统计范围和关键口径。
4. 将事实、预期、分析判断和建议分区表达。
5. 检查结论是否有对应证据、风险是否充分呈现。
6. 对冲突数据、缺失数据、假设和未验证项单独说明。
7. 生成报告并记录版本和生成时间。

## 4. 标准结构

1. 摘要与结论；
2. 研究范围、市场与数据时点；
3. 核心事实和证据；
4. 分析过程与判断；
5. 情景、催化与观察指标；
6. 风险、反向证据及失效条件；
7. 附录：来源、口径、假设和未取得数据。

## 5. 规则

- 不把旧数据包装成今天的结论。
- 不把预测或模型观点写成事实。
- 不使用无来源的精确目标价或胜率。
- 不隐藏不利证据和分析局限。
- 用户要求简报时控制长度；要求完整报告时保留可复核依据。

## 6. 输出

完整报告或用户指定格式的摘要，并附数据时间、来源、关键假设、风险与未验证项。
