# 投资绩效分析

## 1. 统计范围

先明确用户、账户、市场、策略、统计期间、币种和样本定义。个人绩效数据必须经过用户/账户授权校验。

## 2. 核心指标

根据数据充分程度选择：
- 总收益/区间收益；
- 已实现与未实现盈亏；
- 时间加权收益率（TWR）或资金加权收益率（MWR/IRR）；
- 胜率、平均盈利、平均亏损和盈亏比；
- 单笔期望收益；
- 最大回撤及回撤持续期；
- 盈利因子；
- 波动率和适当的风险调整指标；
- 换手率、费用和滑点；
- 策略、行业、市场和交易行为分组表现。

## 3. 口径要求

1. 区分账户净值变化与简单买卖价差。
2. 说明现金流如何处理；外部入金/出金会影响收益率计算。
3. 说明费用、税费、分红、拆并股和公司行动处理。
4. 多币种组合需要汇率来源、时点和基准币种。
5. 未平仓头寸使用一致的估值时点，并标注未实现盈亏。
6. 胜率的样本单位应定义为完整交易、已平仓批次或其他口径；不能混用。
7. 样本过少时说明统计不稳定，不进行强结论。
8. 不同策略/市场的周期和风险暴露不同，比较时需要合理基准和统一口径。

## 4. 指标说明

- 胜率 = 盈利样本数 / 已完成样本数；
- 盈亏比应明确采用平均盈利绝对值 / 平均亏损绝对值；
- 盈利因子 = 总盈利 / 总亏损绝对值；
- 最大回撤基于净值曲线峰值到随后谷值的最大跌幅；
- 单笔期望值应基于同一统计样本口径计算。

若分母为零、无样本或数据不全，结果应标记为不适用，而不是返回无穷或虚构数值。

## 5. 输出

统计期间和范围、数据口径、样本数、收益指标、风险指标、策略/市场分组、与基准比较、行为分析、数据限制和改进建议。
