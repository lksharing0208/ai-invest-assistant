# 宏观经济分析

## 1. 分析范围

按用户关注市场选择相关宏观变量：
- 经济增长：GDP、工业生产、消费、投资、就业；
- 通胀：CPI、PPI、工资和通胀预期；
- 货币政策：政策利率、公开市场操作、准备金与流动性；
- 财政政策：财政支出、税收、政府融资；
- 利率曲线：短端、长端、实际利率和期限利差；
- 汇率与国际收支；
- 国际贸易、能源、地缘事件和金融条件。

不要求每次覆盖全部指标，只选择与任务有关且可验证的数据。

## 2. 执行流程

1. 确认国家/地区、市场、分析时点和预测期限。
2. 通过 market-data 获取实际可用的宏观数据与政策信息。
3. 检查发布日期、数据期间、修订记录、季调口径和来源。
4. 区分领先、同步和滞后指标，避免仅凭单一指标判断周期。
5. 建立宏观变量到利率、汇率、盈利、估值和风险偏好的传导链。
6. 至少给出基准情景；存在重要不确定性时补充上行/下行情景。
7. 明确关键假设、时间范围、可能反证和后续观察指标。

## 3. 分析要求

- 区分已发布数据、市场预期、政策表态和分析判断。
- 预测需标明预测期限和情景条件，不写成确定事实。
- 不将相关性直接表述为因果关系。
- 避免只用单一宏观指标解释资产价格。
- 对政策变化标明实际发生日期和信息发布时间。

## 4. 输出

宏观结论、核心数据表（数值/期间/发布日期/来源）、政策变化、传导逻辑、基准及替代情景、对目标市场的潜在影响、风险和观察清单。
