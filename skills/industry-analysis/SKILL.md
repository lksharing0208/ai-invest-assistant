# 行业与板块研究

## 1. 分析范围

按市场和研究主题分析：
- 行业分类和产业链位置；
- 行业规模、供需和景气指标；
- 行业政策、监管与竞争格局；
- 行业收入、利润率、资本开支和库存等基本面；
- 板块价格相对强度、成交和市场广度；
- 主题/概念催化及可持续性；
- 代表公司、上下游关系和集中度。

## 2. 执行流程

1. 明确行业分类标准、市场、时间窗口及用户研究目标。
2. 用 market-data 获取行业指数、成分和财务/产业数据。
3. 检查行业分类版本、成分变更、数据期间和披露时间。
4. 分析基本面景气及供需驱动，不只依据股价表现判断行业质量。
5. 分析板块相对市场和其他行业的强弱、成交与广度。
6. 识别催化事件、政策变化和潜在反转因素。
7. 将行业判断映射至公司研究时，按需交由 stock-research。

## 3. 规则

- 行业分类口径必须明确，不能混用不同分类体系。
- “资金流入/流出”必须说明数据供应商和计算方法；无法验证时使用成交和价格事实，不臆测主力资金。
- 主题热度与长期产业价值分开分析。
- 不能仅由概念关联推断公司实际收入受益。

## 4. 输出

行业定义、产业链、景气数据、政策/供需驱动、板块走势与相对强度、代表公司及关联证据、催化因素、风险和观察指标。
