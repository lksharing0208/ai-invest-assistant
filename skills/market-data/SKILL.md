# 金融数据获取与质量校验

## 1. 职责边界

定义数据需求、调用当前 Runtime 已注册的数据工具、统一字段口径、检查质量并交付可追溯数据。数据供应商和 API 由实际项目/Runtime 配置，本 Skill 不假设不存在的工具或接口。

## 2. 数据需求确认

按任务确定：
- 市场和交易所；
- 标的代码及证券类型；
- 字段与频率（日线、分钟线、快照、财报期间等）；
- 开始/结束日期和时区；
- 币种、复权口径、单位；
- 实时、延迟、历史、公告或预测属性；
- 数据源和授权范围。

## 3. 执行步骤

1. 检查当前可用数据工具、授权、覆盖市场和字段。
2. 使用标准证券标识组合（市场/交易所 + 代码），校验名称及证券类型。
3. 获取满足任务范围的最小数据集，避免重复查询。
4. 保存来源、查询时间、数据时间、市场时区和延迟属性。
5. 检查缺失、重复、乱序、异常值、停牌、交易日和单位。
6. 对财务数据保留报告期、披露日期、币种、合并/母公司口径及修订情况。
7. 对价格数据确认前复权/后复权/不复权，不能混用。
8. 对跨市场数据确认交易时段、节假日、汇率和时间对齐。
9. 输出数据质量状态和不可用字段，不在缺失处编造数值。

## 4. 标准数据封装

每组数据尽量带有：

| 字段 | 含义 |
|---|---|
| instrument_id | 标准标的标识 |
| market / exchange | 市场及交易所 |
| source | 真实数据来源 |
| retrieved_at | 数据获取时间 |
| data_timestamp | 数据对应时间 |
| timezone | 时间时区 |
| currency / unit | 币种及计量单位 |
| data_status | real_time、delayed、historical、reported、estimated 等 |
| adjustment | 复权口径或不适用 |
| period | 数据统计期间/财报报告期 |
| fields | 实际字段和数值 |
| quality_flags | 缺失、异常、冲突等质量标记 |

无法取得的字段使用 null/缺失状态并解释原因，不用猜测值代替。

## 5. 质量门禁

- 证券标识和市场不匹配：阻断后续计算。
- 时间戳、时区或财报报告期缺失：标记为不可直接比较。
- 实时性未确认：不得称为实时行情。
- 复权口径不一致：不得直接计算收益或技术指标。
- 单位/币种不一致：转换前明确汇率来源和时间。
- 样本不完整：说明覆盖范围及其对结论的影响。
- 数据源冲突：保留各源值、来源和差异，不擅自择优隐藏。

## 6. 输出

数据清单、查询范围、来源/时间、口径、质量问题、未取得字段、可用于后续分析的数据集及限制。
