# 交易计划

## 1. 职责边界

将经验证的研究/策略信号转换成可审查的计划。只产出计划和条件，不调用真实下单/撤单能力。若无实时行情，只能给出条件性计划，不能伪称可立即成交。

## 2. 输入要求

- 市场、证券及交易单位；
- 研究时点和策略/信号版本；
- 数据来源、报价时间及延迟；
- 入场触发条件和失效条件；
- 计划周期和用户风险约束；
- 账户现金、已有仓位和授权信息（适用时）；
- 交易成本、最小交易单位和流动性数据。

## 3. 计划构建

1. 核验研究信号和数据是否仍然有效。
2. 明确触发价/条件、观察区间和有效期限。
3. 明确止损逻辑及失效条件，不以任意百分比替代策略规则。
4. 定义止盈或退出管理方案，包括分批退出的条件（如适用）。
5. 与 risk-management 计算风险预算、仓位边界和极端风险。
6. 分析预期风险收益比及交易成本敏感性。
7. 检查市场交易制度、流动性、停牌及不可成交风险。
8. 形成计划版本，注明生成时间和失效时间/事件。

## 4. 规则

- 不把预测价格描述为确定成交价。
- 入场、止损和止盈都必须有逻辑依据。
- 不存在风险配置时明确标记，不自动填充账户承受能力。
- 不建议以追加资金掩盖原计划失效。
- 计划不等于真实订单，也不保证执行结果。
- 真实交易必须由有授权的交易系统另行执行。

## 5. 输出

标的与市场、计划时间、信号来源、入场条件、止损/退出条件、目标情景、数量/仓位计算前提、费用与滑点、风险收益、失效条件和执行前检查。
